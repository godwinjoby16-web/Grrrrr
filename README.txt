WINTER ARC OS — SAMSUNG / ANDROID

This is an installable PWA prototype.
Features: daily habit tracker, XP, word of the day, definition/example/synonyms, speech pronunciation, saved vocabulary, local JARVIS commands, optional browser speech input, fitness and GCSE logs, local storage, JSON export and offline caching.

LIMITATIONS:
- JARVIS is a local command assistant, not a cloud AI chatbot.
- A web app cannot reliably stay always-listening for a wake word while closed.
- Notification permission can be tested, but scheduled notifications while closed need additional push infrastructure or a native Android app.
- Data is stored in this browser on this device. Export backups regularly.
- Full PWA installation requires hosting these files on an HTTPS website. Opening index.html as a file is only a preview.

INSTALL:
1. Publish this folder to an HTTPS static host (for example GitHub Pages).
2. Open its HTTPS address in Chrome on your Samsung.
3. Chrome menu ⋮ > Install app / Add to Home screen.
4. Launch from the new icon. Allow notification permission if desired.
